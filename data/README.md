# Data boundary

The historical maritime dataset used by the validated local Eagle Eye project is not redistributed in this public repository. Its source was made available to the thesis project, and the thesis does not assert a public redistribution licence.

The public checkout keeps the already-public `demo_data` fallback for interface and contract testing. To use the complete validated local capability set, place an authorised data bundle under `data/processed` and build the local documentary index under `data/chroma` according to the project documentation. Benchmark results do not transfer automatically to replacement data.
